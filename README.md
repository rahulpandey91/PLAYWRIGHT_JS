# Prerequisites to start with Playwright

[Install Nodejs latest version](https://nodejs.org/en/download) < br / >
[Install Visual Code Studio IDE](https://nodejs.org/en/download)

## Installation

Use the package manager [npx](https://docs.npmjs.com/cli/v8/commands/npx) to install all the supported browser.

```bash
npx playwright install
```

## Run Project on QA Environment

```bash
npm run qa
```

## Run Project on STAGE Environment

```bash
npm run stage
```

## Generate Allure report

```bash
npm run generate
```

## To open Allure report

```bash
npm run allure
```
